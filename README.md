# python-to-do-list

Python To-Do List App

Project Description

A simple desktop To-Do List application developed using Python and Tkinter. It helps users manage their daily tasks by adding, deleting and marking tasks as completed. Tasks are saved automatically using JSON file storage.

Features

* Add new tasks
* Delete selected tasks
* Mark tasks as completed or undo completion
* Clear all tasks
* Automatic task storage
* Tasks remain saved after restarting the application

Technologies Used

* Python
* Tkinter
* JSON

How to Run

1. Install Python.
2. Download or clone the repository.
3. Open the folder in VS Code.
4. Open the terminal.
5. Run:

python todo_list.py

Project Files

* todo_list.py – main Python application.
* tasks.json – automatically stores task information.
